# VKTask2 - Погодный отчёт по городам

## Описание

Консольное приложение на C#, которое:

- Загружает список городов из текстового файла.
- Для каждого уникального города получает текущие данные о погоде через API `https://wttr.in/{City}?format=j1`.
- Формирует модель `WeatherData` с полями: город, страна, текущая температура в градусах Цельсия.
- Выводит информацию по каждому городу в формате `Город, Страна +Температура °C`.
- Группирует города по странам и выводит для каждой страны: количество городов, среднюю, минимальную и максимальную
  температуру.

## Запуск

2. Убедитесь, что в корне проекта есть файл `Cities.txt` со списком городов (по одному на строку).

3. Запустите приложение:

   ```bash
   VKTask2.exe
   ```
   Если файл с городами находится в другом месте, можно передать путь аргументом:
   ```bash
   VKTask2.exe /путь/к/Cities.txt
   ```

## Структура

| Файл             | Назначение                                                                                                                                      |
|------------------|-------------------------------------------------------------------------------------------------------------------------------------------------|
| `Program.cs`     | Точка входа: чтение файла, последовательный обход городов, вывод результатов и статистики.                                                      |
| `WeatherData.cs` | Модель данных о погоде (город, страна, температура). Переопределён `ToString()` для форматированного вывода.                                    |
| `Wttr.cs`        | Класс для работы с API `wttr.in`: HTTP-запрос, десериализация JSON, извлечение нужных полей. Содержит вспомогательные классы для маппинга JSON. |
| `VKTask2.csproj` | Файл проекта .NET.                                                                                                                              |
